## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)`.
5. Save and wait for the Pages URL.

### Note about hover previews
The portfolio keeps YouTube out of the thumbnail area to avoid YouTube ads/branding during browsing. Clicking a project opens its YouTube video at the exact saved edit start time. If you later provide short MP4 preview clips, the project cards can be upgraded to true ad-free hover-to-play previews.
